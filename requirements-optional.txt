# Meshwright — optional engines (Geekatplay Studio)
#
# The installer installs these ONE AT A TIME and keeps going if one fails.
# Every entry is detected at runtime: if it is absent Meshwright drops that
# specific method and says so, it never crashes (see docs/LICENSES.md).
#
# Why they are separate: these are compiled extensions, and a brand-new Python
# release usually has no ready-made build for a few of them for some months.
# `pip install -r` is all-or-nothing, so one missing build used to abort the
# entire installation.
#
# Installing them by hand:
#     .venv\Scripts\python -m pip install -r requirements-optional.txt
