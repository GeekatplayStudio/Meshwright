      Meshwright

      Mesh analysis, repair and STL preparation for 3D printing

      Geekatplay Studio · Vladimir Chopine

      ☕ Buy me a coffee — support Meshwright development

      What it does

      Meshwright takes any common 3D model, tells you exactly why it would fail on a 3D printer, fixes it while reporting what changed, and exports a print-ready model resting on the build plate.

      How it works

      1. Load — OBJ, FBX, GLB/GLTF, STL, PLY, 3MF, DAE, OFF are read with trimesh (ufbx and MeshLab as fallbacks); materials are skipped and duplicate vertices merged.
      2. Diagnose — open holes, boundary and non-manifold edges, face winding, inside-out normals, degenerate, duplicate and sliver triangles, unused vertices, separate shells, scale, volume and genus. Every issue carries its location so it can be highlighted on the model. A 0–100 readiness score summarises the result.
      3. Repair — a staged pipeline where each stage is measured and kept only if it helps: cleanup → orientation → small-hole filling → MeshFix → MeshLab non-manifold repair → Manifold3D solid reconstruction → voxel remesh as last resort. It re-runs until the mesh stops changing, then re-analyses the final result.
      4. Refine — sliver triangles are merged into larger neighbours (needles collapsed, caps flipped); polygon count is reduced three ways — QuadriFlow smart retopology (clean curvature-aligned quads, true low-poly), uniform isotropic remeshing, or topology-preserving quadric collapse — always with the measured surface deviation; separate pieces can be highlighted and removed; the model can be rotated with a gizmo or in 90° steps.
      5. Safeguards — every change is a numbered state with undo/redo. A change that would add critical problems or discard most of the geometry is rejected unless you apply it anyway. Every state is snapshotted in the background so a crash can be recovered on the next start.
      6. Export — STL (binary), OBJ, PLY, OFF, GLB, glTF or 3MF with unit scaling and build-plate alignment, plus a JSON report of the diagnostics and every operation applied. The result is measured as it is written: inside-out models are turned the right way out, and a file that is not a closed solid says so — a slicer prints an open surface as a single-wall shell with no infill.

      Engines in use

      Viewport: Three.js · Desktop shell: pywebview (Edge WebView2) · Python on

      Integrations

      The same engine is available to AI assistants and editors through an MCP server (python mcp_server.py), directly from Python (engine.service.MeshService), and as custom nodes for ComfyUI.
